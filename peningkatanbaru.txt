1. Fitur Searching (Index & Admin)
Di CodeIgniter 4, pencarian + pagination itu seringkali tricky (saat klik halaman 2, pencariannya hilang). Kita akan buat yang persisten.

Langkah A: Update EntriController.php
Buka file src/Controllers/EntriController.php. Kita akan modifikasi method index() (untuk publik) dan admin() (untuk admin) agar bisa menangangkap kata kunci.

PHP

// Buka src/Controllers/EntriController.php

public function index()
{
    $keyword = $this->request->getVar('keyword');
    
    // Logic Pencarian
    if ($keyword) {
        $this->entriModel->like('term', $keyword)
                         ->orLike('definition', $keyword);
    }

    $data = [
        'title' => 'Kamus Leksikon',
        // Pagination otomatis akan membaca query sebelumnya jika model dipanggil berantai
        'entri' => $this->entriModel->paginate(10, 'entri'), 
        'pager' => $this->entriModel->pager,
        'keyword' => $keyword // Kirim balik keyword ke view biar input gak hilang
    ];

    return view('entri/index.view', $data);
}

public function admin()
{
    // Cek login admin (Asumsi sudah ada filter/middleware, jika belum tambahkan manual)
    if (!session()->get('isLoggedIn') || session()->get('role') != 'admin') {
        return redirect()->to('/login');
    }

    $keyword = $this->request->getVar('keyword');

    if ($keyword) {
        $this->entriModel->like('term', $keyword)
                         ->orLike('definition', $keyword);
    }

    $data = [
        'title' => 'Dashboard Admin',
        'entri' => $this->entriModel->paginate(10, 'entri'),
        'pager' => $this->entriModel->pager,
        'keyword' => $keyword
    ];

    return view('entri/admin.view', $data);
}

2. UI Improvement (Apakah sudah rapi?)
Melihat style.css kamu, konsep Neobrutalism-nya sudah kuat (border: 2px solid #000, box-shadow: 4px 4px 0px #000). Itu sudah sangat rapi dan unik.

Tapi, ada 2 hal kecil yang bisa bikin UI kamu makin "mahal":

A. Highlight Kata Kunci (UX Plus)
Saat user mencari "makan", akan sangat membantu jika di hasil pencarian kata "makan" itu diberi warna kuning stabilo.

Tambahkan helper function ini di src/functions.php (atau buat baru jika belum ada):

PHP

// Helper untuk highlight teks
function highlight_keyword($text, $keyword) {
    if (!$keyword) return $text;
    // Highlight dengan background kuning neo-brutalist
    return preg_replace(
        '/(' . preg_quote($keyword, '/') . ')/i', 
        '<span style="background-color: #ffeb3b; border: 1px solid #000; padding: 0 2px;">$1</span>', 
        $text
    );
}
Lalu gunakan di View (index.view.php):

PHP

<td><?= highlight_keyword(esc($item['term']), $keyword ?? '') ?></td>
<td><?= highlight_keyword(esc($item['definition']), $keyword ?? '') ?></td>
(Pastikan kamu tidak meng-esc hasil highlight, atau gunakan esc() di dalam fungsi sebelum di-replace).

B. Loading State untuk Portal (Penting!)
Karena kamu punya fitur "Portal 5 Website", jika salah satu website lemot, halaman webmu akan terasa hang. Pastikan kamu menggunakan AJAX Loading yang kita bahas sebelumnya, atau minimal kasih indikator loading CSS di tombol cari porta
